## What is in the box

<CardGrid stagger>
  <Card title="Dashboard" icon="laptop">
    See servers, accounts, streams, consumers and Raft groups of every cluster. Edit stream config, step down leaders, purge and delete, with roles. The JetStream view updates live over SSE.
  </Card>
  <Card title="Health" icon="warning">
    One list of what misbehaves, most severe first: stale consumers, full ack windows, streams near a limit, groups without a leader and ghost peers.
  </Card>
  <Card title="MCP server" icon="puzzle">
    Give Claude or any MCP client tools to inspect a cluster. Read-only by default. Write tools and message sampling are opt-in.
  </Card>
  <Card title="Protobuf-aware pub/sub" icon="seti:json">
    `sub` and `pub` decode and encode protobuf with schemas loaded at run time. Private `.proto` files never go into the binary.
  </Card>
  <Card title="Safe cleanup" icon="approve-check">
    Find stale consumers, ghost peers and unbounded streams. Cleanup works like a code review: scan, edit a manifest, apply. Apply checks each consumer again just before it deletes it.
  </Card>
  <Card title="Chat bot" icon="comment">
    Run the scans on a schedule, post the results to Slack or Mattermost, and approve a cleanup with a signed link.
  </Card>
</CardGrid>

## Only port 4222

cheshmhayash talks to your clusters over the NATS protocol itself. It uses the same system-account subjects (`$SYS.REQ.*`) and JetStream API (`$JS.API.*`) as `natscli`. You do not need to open the HTTP monitoring port (`:8222`).
